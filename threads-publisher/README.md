# Threads Publisher

Automated publishing to Threads through the official Meta Threads API and GitHub Actions.

## What is already configured

- `publish_threads.py` publishes text posts and optional image posts through `graph.threads.net`.
- `posts.json` is the publishing queue.
- `state.json` prevents queued posts from being published twice.
- `.github/workflows/threads-publisher.yml` checks the queue every 15 minutes.
- The workflow can also be started manually in GitHub Actions for an authentication check or a one-off post.

## One-time Meta setup

1. Open Meta for Developers and create/open an app.
2. Add/customize the **Access the Threads API** use case.
3. Make sure the app has at least these permissions:
   - `threads_basic`
   - `threads_content_publish`
4. Add the target Threads account as a **Threads Tester**.
5. In Threads, accept the invitation under **Settings → Account → Website permissions → Invites**.
6. Back in Meta Developers, open **Use cases → Access the Threads API → Customize → Settings**.
7. In **User Token Generator**, generate an access token for the accepted tester account.
8. Copy the generated token. Do not put it in a repository file or commit it.

## Add the token to GitHub

In repository `KostttS/KostttS`:

**Settings → Secrets and variables → Actions → New repository secret**

Create exactly this secret:

- Name: `THREADS_ACCESS_TOKEN`
- Value: the Threads access token generated by Meta

The publisher resolves the Threads user ID automatically from `/me`, so no user ID secret is needed.

## Test authentication

Open:

**Actions → Threads Publisher → Run workflow**

Choose `check` and run it.

A successful run prints the authenticated Threads username and `Threads API authentication check passed.`

## Queue format

Add entries to `posts.json` like this:

```json
[
  {
    "id": "2026-09-09-olimp-01",
    "publish_at": "2026-09-09T18:30:00+03:00",
    "text": "Post text"
  },
  {
    "id": "2026-09-10-olimp-image-01",
    "publish_at": "2026-09-10T10:00:00+03:00",
    "text": "Post text with an image",
    "image_url": "https://example.com/public-image.jpg"
  }
]
```

`publish_at` may use a timezone offset. The workflow checks every 15 minutes and publishes due posts that are not present in `state.json`.

## Manual one-off post

Open **Actions → Threads Publisher → Run workflow**, choose `manual`, enter the text and optionally a public image URL.

## Security

Never commit the access token, app secret, or authorization code into the repository. Keep the Threads access token only in GitHub Actions Secrets.

Threads long-lived access tokens expire and must be refreshed/replaced before expiry. If publishing starts failing with an authentication error, generate/refresh the token in Meta and replace `THREADS_ACCESS_TOKEN` in GitHub Actions Secrets.
